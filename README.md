# Rüyam Bayan Kuaför Mobile Application Project

## Introduction
Rüyam Bayan Kuaför is a mobile application designed to provide users with an easy and efficient way to book beauty services. It bridges the gap between customers and beauty salons, offering a user-friendly interface to browse services, read reviews, and manage appointments.

## Features
- **Service Booking:** Users can select and book beauty services at their convenience.
- **Salon Directory:** A comprehensive list of nearby salons with detailed information and user reviews.
- **User Profiles:** Users can create profiles to manage their bookings and preferences.
- **Notifications:** Alerts for upcoming appointments and special offers.

## Technology Stack
- Frontend: React Native
- Backend: Node.js with Express
- Database: MongoDB
